# Тесты бэкенда

Запуск из папки `project`:

```bash
.venv/bin/python -m pytest notes-tests -v
```

Или в VS Code: вкладка **Testing** (колба слева) либо зелёный ▶ возле теста.

Каждый тест работает с чистой временной базой, `backend/notes.db` не трогается.

| Файл | Что проверяет |
|------|---------------|
| `test_auth.py` | регистрация, вход, выход |
| `test_notes.py` | создание, изменение, удаление заметок; чужие заметки не видны |
| `test_security.py` | хеширование паролей |
| `test_app.py` | сервер отдаёт фронтенд |
